Large-Graph Visualisation — Overview Demo

The renderer benchmark pages in one place: one live prototype per library, all fed the same real knowledge graph — up to 139K nodes / 1.1M edges.

Verdict: Sigma.js with an offline-precomputed layout wins at scale (~100 fps @ 1.1M edges); deck.gl is the ultra-light runner-up.

Benchmarks — renderers ranked by measured FPS @ 1.1M edges

Notes

  • Node colour = type (paper / patent / product / trial); size ∝ √degree.
  • Precomputed variants (Sigma · precomputed, Cosmograph · precomputed, cosmos.gl, deck.gl, 3d-force-graph) render a layout baked offline (FA2 coordinates in *.layout.json); live variants (Sigma · live, Cosmograph · live) lay out in-browser.
  • Run on a real GPU (your Mac) for accurate FPS — headless/CI browsers fall back to software rendering.
  • This page is the hub of the demo site — npm run dev (or npx vite) for live dev, or npm run build + any static server for the built site.
